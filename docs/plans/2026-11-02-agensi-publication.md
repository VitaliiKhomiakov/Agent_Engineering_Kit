Agensi accepts a ZIP with SKILL.md and serves at most 200 supporting text files.

Use one marketplace entry and grouped reference documents retaining source text,
with a source-path index and provenance. Include all current standards and
operational templates; history and maintenance programs stay at the source.
The public listing must explain that persistent project adoption uses the
independent GitHub source and its existing SETUP/MIGRATION procedure.
Do not label the repository MIT/open-source or invent a license: no LICENSE file
was found. Do not bundle the separately installed Superpowers plugin.
