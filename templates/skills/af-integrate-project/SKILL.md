# Integrate project rules

Deliver a reviewable preparation or the authorized import/update. Use the source
framework's `MIGRATION.md` as the procedure owner; preserve the selected stage
checkpoints. This is an instruction-only entry, with no installer or model setup.

## Resolve the source and target

Reuse the supplied source, target roots/checkouts, client, intent and canonical
task. For an existing adoption, read target `.agents-framework/adoption.md` for
source identity and owned scope. Ask only for material missing information.

When read directly at source `templates/skills/af-integrate-project/SKILL.md`,
the framework root is three directories above this skill folder; verify its
`MIGRATION.md` and `standards/catalog.toml`. When installed, resolve the accessible
framework source from the request or adoption record, independently of the skill's
directory. Never assume the target contains MIGRATION or is the source library.
If that source is unavailable, identify the missing resource before dependent
preparation/application; do not invent policy or globally install another copy.

Paths in this table resolve from the identified framework source. Select sections
by their headings; follow further references only for the requested operation.

Prepare source/profile/path/action/content and conflict decisions under that
procedure. Preparation-only intent leaves the target untouched. For application,
reuse existing authorization, preserve originals and reconcile intervening edits;
replace loaded conflicts while retaining required local contracts and gates.
Keep existing task stores and model choices. Ordinary imports need no delegation
or model-setup questionnaire. Preserve scope, typing and proportionate verification
rules when adapting entries; catalog availability is not unconditional reading.

Report prepared/applied/unchanged/partial scope, evidence, unresolved decisions and
the next agreed checkpoint. Distinguish valid files from observed client discovery.
Neither source-based reading nor copying this skill proves native activation.
