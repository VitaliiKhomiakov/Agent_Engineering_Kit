# Set up Agent Engineering Kit

For the AI agent: read and follow the
[integration wizard](templates/skills/aek-integrate-project/SKILL.md).

Resolve the link from the directory containing `SETUP.md`; that directory is the
framework source. Keep the user's target project distinct from that source;
do not assume the library itself is the intended target.

Pass through the supplied target path, client, requested operation, existing
choices and permissions. The skill owns the menu, questions and progress;
[MIGRATION.md](MIGRATION.md) owns the adoption procedure.
