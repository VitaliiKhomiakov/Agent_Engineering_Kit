# Example: authorized HTTP command with an independent invariant

Read when a Next.js request contract must be distinguished from current-state
eligibility. This optional example supports [server security](../server-client-security.md).
It and the [tagged-read example](tagged-read.md) are two scenarios in one temporary
App Router fixture. Assemble both sets of files before building; their setup and
runner are shared rather than duplicated. Neither is a deployable authentication,
inventory or caching service.

The HTTP adapter validates identity, capability, media type and one exact JSON
shape. The operation also protects permission and positive quantity for direct
callers. A failed reservation does not change stock. The route projects a public
result and marks its response no-store. Unknown fields, numeric strings and unsafe
integers are refused intentionally, not coerced by TypeScript.

`authenticate` is a test identity adapter using two opaque tokens generated by the
runner and supplied to the server's environment. It is not a session product: there
is no issuer, revocation, expiry or deployment secret store. Explicit Authorization
headers avoid implying a cookie/CSRF implementation. Replace it with the project's
verified provider and operation policy in real work. Never trust client-supplied
roles. The stock variable is scoped to one route module/server worker; a production
backend needs atomic persistence and idempotency. This fixture does not test request
byte/time/rate budgets; production ingress/application limits remain required where
applicable. `request.json()` alone provides no such budget.

### `features/reserve/stock.ts`

```ts
export interface Actor { readonly canReserve: boolean }
export interface ReserveCommand { readonly quantity: number }
export type StockResult = { readonly kind: 'reserved'; readonly remaining: number }
  | { readonly kind: 'forbidden' } | { readonly kind: 'invalid' }
  | { readonly kind: 'unavailable' };

export function parseCommand(value: unknown): ReserveCommand | null {
  if (typeof value !== 'object' || value === null || Array.isArray(value)
    || !('quantity' in value) || Object.keys(value).length !== 1
    || typeof value.quantity !== 'number' || !Number.isSafeInteger(value.quantity)
    || value.quantity <= 0) return null;
  return { quantity: value.quantity };
}

export function reserveStock(actor: Actor, available: number, command: ReserveCommand): StockResult {
  if (!actor.canReserve) return { kind: 'forbidden' };
  if (!Number.isSafeInteger(command.quantity) || command.quantity <= 0) return { kind: 'invalid' };
  if (!Number.isSafeInteger(available) || available < 0) throw new RangeError('Invalid stock');
  if (command.quantity > available) return { kind: 'unavailable' };
  return { kind: 'reserved', remaining: available - command.quantity };
}
```

### `features/reserve/session.ts`

```ts
import 'server-only';
import type { Actor } from './stock';

// A deterministic server-side identity fixture, not a production session provider.
export function authenticate(request: Request): Actor | null {
  const editor = process.env.AF_EDITOR_TOKEN;
  const viewer = process.env.AF_VIEWER_TOKEN;
  if (!editor || !viewer || editor === viewer) throw new Error('Session fixture not configured');
  const token = request.headers.get('authorization');
  if (token === `Bearer ${editor}`) return { canReserve: true };
  if (token === `Bearer ${viewer}`) return { canReserve: false };
  return null;
}
```

### `app/api/reservations/route.ts`

```ts
import { authenticate } from '../../../features/reserve/session';
import { parseCommand, reserveStock } from '../../../features/reserve/stock';

// One-worker fixture only. Real operations own atomic persistence and idempotency.
let available = 3;
interface FailureBody { readonly error: string }
interface ReservationBody { readonly remaining: number }
function reply(body: FailureBody | ReservationBody, status: number): Response {
  return Response.json(body, { status, headers: { 'Cache-Control': 'no-store' } });
}
export async function POST(request: Request): Promise<Response> {
  const actor = authenticate(request);
  if (!actor) return reply({ error: 'unauthenticated' }, 401);
  if (!actor.canReserve) return reply({ error: 'forbidden' }, 403);
  if (request.headers.get('content-type')?.split(';')[0]?.trim() !== 'application/json') {
    return reply({ error: 'unsupported_media_type' }, 415);
  }
  let payload: unknown;
  try { payload = await request.json(); }
  catch { return reply({ error: 'invalid_json' }, 400); }
  const command = parseCommand(payload);
  if (!command) return reply({ error: 'invalid_command' }, 400);
  const result = reserveStock(actor, available, command);
  if (result.kind !== 'reserved') {
    return reply({ error: result.kind }, result.kind === 'unavailable' ? 409 : 400);
  }
  available = result.remaining;
  return reply({ remaining: result.remaining }, 201);
}
```

### `tests/http.ts`

```ts
import assert from 'node:assert/strict';
import { spawn } from 'node:child_process';
import { once } from 'node:events';
import { mkdtemp, readFile, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { randomUUID } from 'node:crypto';
import { test } from 'node:test';
import { reserveStock } from '../features/reserve/stock.ts';

const directory = await mkdtemp(join(tmpdir(), 'af-next-http-'));
const catalogPath = join(directory, 'catalog.json');
const editor = randomUUID();
const viewer = randomUUID();
const secret = 'PRIVATE_CATALOG_SENTINEL';
await writeFile(catalogPath, JSON.stringify({ title: 'Initial catalog', internalCost: secret }));
const child = spawn(process.execPath, ['node_modules/next/dist/bin/next', 'start', '-H', '127.0.0.1', '-p', '0'], {
  env: { ...process.env, NEXT_TELEMETRY_DISABLED: '1', NO_COLOR: '1',
    AF_EDITOR_TOKEN: editor, AF_VIEWER_TOKEN: viewer, AF_CATALOG_FILE: catalogPath },
  stdio: ['ignore', 'pipe', 'pipe'],
});
let output = '';
child.stdout.setEncoding('utf8');
child.stderr.setEncoding('utf8');
child.stdout.on('data', (chunk: string) => { output += chunk; });
child.stderr.on('data', (chunk: string) => { output += chunk; });
const started = Promise.withResolvers<string>();
const timer = setTimeout(() => started.reject(new Error('Next start timeout')), 20_000);
child.once('error', started.reject);
child.once('exit', code => started.reject(new Error(`Next exited before readiness: ${code}`)));
child.stdout.on('data', () => {
  const url = /Local:\s+(http:\/\/127\.0\.0\.1:\d+)/.exec(output)?.[1];
  if (url && /Ready in/.test(output)) started.resolve(url);
});

try {
  const base = await started.promise;
  clearTimeout(timer);
  async function request(path: string, init?: RequestInit): Promise<Response> {
    return fetch(`${base}${path}`, { ...init, signal: AbortSignal.timeout(5000) });
  }
  async function reserve(body: string, token: string | null = editor,
    media = 'application/json'): Promise<Response> {
    return request('/api/reservations', { method: 'POST', body,
      headers: { 'Content-Type': media, ...(token ? { Authorization: `Bearer ${token}` } : {}) } });
  }
  async function json(response: Response): Promise<unknown> { return response.json(); }
  await test('actual HTTP entry refuses missing identity, forbidden identity and malformed input', async () => {
    assert.equal((await reserve('{"quantity":1}', null)).status, 401);
    assert.equal((await reserve('{"quantity":1}', 'forged')).status, 401);
    assert.equal((await reserve('{"quantity":1}', viewer)).status, 403);
    assert.equal((await reserve('{"quantity":1}', editor, 'text/plain')).status, 415);
    for (const body of ['{', 'null', '[]', '{}', '{"quantity":"1"}', '{"quantity":0}',
      '{"quantity":-1}', '{"quantity":1.5}', '{"quantity":9007199254740992}',
      '{"quantity":1,"canReserve":true}']) {
      assert.equal((await reserve(body)).status, 400, body);
    }
  });
  await test('state refusal cannot spend stock and successful output is projected', async () => {
    const first = await reserve('{"quantity":2}');
    assert.equal(first.status, 201);
    assert.deepEqual(await json(first), { remaining: 1 });
    assert.equal(first.headers.get('cache-control'), 'no-store');
    assert.equal((await reserve('{"quantity":2}')).status, 409);
    const last = await reserve('{"quantity":1}');
    assert.equal(last.status, 201);
    assert.deepEqual(await json(last), { remaining: 0 });
    assert.equal((await reserve('{"quantity":1}')).status, 409);
  });
  await test('operation authority and quantity invariant also apply to direct callers', () => {
    assert.deepEqual(reserveStock({ canReserve: false }, 3, { quantity: 1 }), { kind: 'forbidden' });
    for (const quantity of [0, -1, 0.5, Number.NaN]) {
      assert.deepEqual(reserveStock({ canReserve: true }, 3, { quantity }), { kind: 'invalid' });
    }
  });
  await test('server rendering projects only public data across the client boundary', async () => {
    const response = await request('/');
    assert.equal(response.status, 200);
    const html = await response.text();
    assert.match(html, /Initial catalog/);
    assert.match(html, /Catalog details/);
    assert.equal(html.includes(secret), false);
    assert.equal(html.includes('internalCost'), false);
  });
  await test('tagged read stays cached until authorized immediate expiration', async () => {
    const initial = await request('/api/catalog');
    assert.equal(initial.status, 200);
    assert.deepEqual(await json(initial), { title: 'Initial catalog' });
    await writeFile(catalogPath, JSON.stringify({ title: 'Updated catalog', internalCost: secret }));
    assert.deepEqual(await json(await request('/api/catalog')), { title: 'Initial catalog' });
    assert.equal((await request('/api/revalidate', { method: 'POST' })).status, 401);
    assert.equal((await request('/api/revalidate', { method: 'POST',
      headers: { Authorization: `Bearer ${viewer}` } })).status, 403);
    assert.deepEqual(await json(await request('/api/catalog')), { title: 'Initial catalog' });
    assert.equal((await request('/api/revalidate', { method: 'POST',
      headers: { Authorization: `Bearer ${editor}` } })).status, 204);
    assert.deepEqual(await json(await request('/api/catalog')), { title: 'Updated catalog' });
    assert.match(await (await request('/')).text(), /Updated catalog/);
  });
  await test('uncached request-time response is not confused with a static export', async () => {
    const response = await request('/api/catalog');
    assert.equal(response.headers.get('cache-control'), 'no-store');
    assert.equal((await request('/api/reservations', { method: 'GET' })).status, 405);
    assert.equal((await readFile(catalogPath, 'utf8')).includes('Updated catalog'), true);
  });
} finally {
  clearTimeout(timer);
  if (child.exitCode === null && child.signalCode === null) {
    const exited = once(child, 'exit');
    child.kill('SIGTERM');
    const force = setTimeout(() => child.kill('SIGKILL'), 5000);
    await exited;
    clearTimeout(force);
  }
  await writeFile(join(directory, 'server.log'), output);
  console.log(`HTTP fixture and server log: ${directory}`);
}
```

## Evidence and limits

The six named checks cover denied identity/capability, unsupported media and ten
malformed/extra/coerced bodies; stock refusal/success and output projection; direct
operation invariants; server-rendered public output; cross-request cache reuse and
authorized invalidation; response cache policy and unsupported method status.
All six passed against `next start` after a production build, with strict unhandled
rejections. Strict TS, framework type checking and Next/typed ESLint passed.

No TLS/reverse proxy, cookie auth/CSRF, request-budget enforcement, concurrent durable
write, multi-instance stock, network failure/retry, Server Action dispatcher or
browser interaction was tested. Unexpected infrastructure errors remain server
errors; this fixture does not implement production observability. Server output is
not browser hydration/visual evidence. Read the tagged example for cache-specific
limits and the import-boundary check.
