# Go / Gin

Compatibility entry for existing `go-gin` selections. New imports select
[Go](go.md) and, when used, [Gin](gin.md). This aggregate keeps both resource
sets available; it does not require reading unused framework guidance.

## Essential guidance

Use [Go guidance](go.md#essential-guidance) with the common engineering rules.

## Read by task

Start with the relevant [Go task](go.md#read-by-task). For actual Gin work,
also use the [Gin task table](gin.md#read-by-task). Examples remain optional;
do not traverse every link recursively.

## Gin essentials

Apply [Gin essentials](gin.md#gin-essentials) only where Gin is used.

## Evidence

The [Go](go.md#evidence) and [Gin](gin.md#evidence) entries retain their sources
and example-check records. This aggregate adds no runtime evidence.
